## Page Template Requirements

Each service page should include:

- Clear H1 with service + location scope where natural
- 120–160 character meta description
- Canonical URL
- Breadcrumbs
- Service intro
- Approved service list
- “Where we serve” local section
- Permit/HOA caution when exterior/electrical/plumbing work could trigger requirements
- Quote CTA
- FAQ section only if useful and visible
- Matching Service schema / OfferCatalog entry

## Location Pages

Sun City page:
- Primary location page.
- Emphasize homeowner maintenance, safety lighting, security cameras, water treatment, EV charging, and punch-list help.
- Avoid HOA endorsement.
- Include caution for exterior-visible modifications.

Berry Creek page:
- Secondary location page.
- Mention Georgetown/Berry Creek service-area context.
- Avoid detailed HOA claims unless current documents are verified.

Georgetown page:
- City-wide support page for 78626/78627.
- Keep Sun City/Berry Creek internally linked.

## Content To Avoid

- Fake project case studies
- Fake reviews
- Fake certification badges
- Construction/industrial pages
- Full remodeling pages
- HVAC/roofing/deck-building/fence-building/full-painting pages
