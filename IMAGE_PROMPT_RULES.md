# Image Prompt Rules

## Default Style

Premium, photorealistic, clean commercial website imagery for a trustworthy Georgetown-area home services company.

## Mark Walbert Persona

When reference photos are provided, preserve Mark’s general:

- facial structure
- build
- hairstyle
- glasses/sunglasses when appropriate
- friendly expression
- practical, local service-provider appearance

Mark should look real, local, approachable, confident, experienced, and professional.

## Approved Visual Themes

- Home maintenance
- Electrical repair
- Lighting installation
- EV charger installation
- Video doorbell
- Security camera
- Smart security panel
- Residential plumbing, simplified
- Water heater, simplified
- Water softener / filtration, simplified
- Handyman repairs
- Clean residential Georgetown/Sun City-style settings

## Visual Exclusions

Do not include:

- HVAC units
- air conditioners
- furnaces
- ductwork
- roofing
- fencing
- decks
- painting equipment
- large construction scenes
- industrial construction
- exposed unsafe wiring
- overcomplicated plumbing
- fake badges/licenses
- unreadable technical labels
- cluttered tool piles

## Mechanical Accuracy Rules

- Simpler is better than complex and wrong.
- Avoid complex pipe networks.
- Avoid crossed/floating/disconnected pipes.
- Avoid open electrical panels unless specifically requested and technically controlled.
- EV chargers should be wall-mounted, neat, safe-looking, with no loose wiring.
- Water heaters should be simple tank-style only if visible details can be believable.
- Water treatment should show a simple tank/filter arrangement with minimal piping.

## Default Hero Size

- 1920x1080 unless otherwise specified.
