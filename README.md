# Mark's Services

PHP 8.4 website for Mark's Services, serving Sun City 78633 and Berry Creek Estates 78628, Texas.

## Local development

Run:

php -S localhost:8080

Then open:

http://localhost:8080

## Environment

Use .env.example as the template for private environment variables.

Do not commit a real .env file.

## Deployment

GitHub main is the source branch for deployment.
